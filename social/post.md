# 广工商大｜把校园卡电费放进桌面

把每天要看的校园余额，整理成了 iPhone 小组件和电脑面板。

广东工商职业技术大学的校园卡余额、宿舍电费，现在可以在 iPhone 上用 Scriptable 小组件查看，也可以在电脑上用 Web 面板查看。

这次主要整理了三件事：
① 保留手机上原来的点阵小组件，以及原 Dashboard 的校园卡片、走势图和记录表。更新失败会标记上次结果。
② 补了参数配置教程，区分查询时间和学校更新时间。
③ 尝试降低配置门槛：在已登录的官方网页选好自己的宿舍，再用本机导出工具生成配置，不用逐层手抄楼栋、楼层、房间 ID。

第三项目前核对了官方网页代码，也做了模拟测试；真实登录会话、微信内导出仍待验证；独立小组件已单独检查手机演示渲染。微信和 Safari 不一定共享登录，所以保留了抓包备用教程，不承诺所有人免抓包。

项目已放 GitHub：
JasonBeam / gdbtu-campus-balance
https://github.com/JasonBeam/gdbtu-campus-balance

README 有运行方法、Scriptable 脚本、配置提取教程和审查记录。想试的同学可以先跑演示模式，看完再配置自己的参数；遇到问题提 Issue 时不要贴 Token、学号或宿舍信息。

封面与配图使用实际截图排版。小组件图来自我手机的真实预览，保留真实数值；Web 截图的金额和走势为演示数据。非学校官方项目。
