# 一次登录，直接用双余额小组件

这是 0.2.0-candidate8 试用版，将学校登录、宿舍选择和余额显示放进一个独立 Scriptable 脚本。完整连续流程已通过本地模拟测试，尚未完成 iPhone 真机验收。学校门户可能显示 “Errors Logged”，不能保证每次登录与查询成功。

## 你要做的事

1. 安装 Scriptable，导入新版「校园余额」脚本。
2. 运行脚本，点 **登录学校 · 自动获取**。
3. 页面先显示“正在连接学校”，随后进入学校官方登录。输入自己的账号、密码和可能出现的验证码。登录后自动继续，中途不用点 **Close／关闭**。
4. 脚本遮住门户和钱包显示连接进度，读取学校登记宿舍后，在当前页面匹配自己的电表。遇到同名公寓时确认一次；学校没有登记完整地址时，按校区、公寓、楼栋和房间手动选择。
5. 核对查到的校园卡余额、宿舍和电费，点 **保存配置**。当前页面显示保存结果，最后关闭页面可查看小组件预览。
6. 在 iPhone 桌面添加 Scriptable 小组件，选择这个脚本。已有用户可继续使用原来的显示样式，不需要导入第二份显示代码。

用户本人输入密码；脚本不读取密码输入框、不代替学校提交登录，也不保存密码。登录成功后，学校会话和选定的电表配置在确认保存后存入本机 Scriptable Keychain。学校网络、登录、验证码或接口变化都可能导致这一步需要调整。

## 和原有脚本怎么配合

新版自身已经包含原来的点阵双余额显示，登录完成即可查看，无需再搬运参数。如果你想接入另一个兼容脚本，选择「更多工具 → 导出自己的配置」，保存为 `config.local.json`，然后在兼容的目标脚本里导入。电脑面板对新电表字段的兼容性尚未验证。导出文件含个人会话，请只保留给自己，不要发群、上传 GitHub 或交给 AI。

`buildingID` 是学校返回的最终查询位置；新增的可选 `meterID` 是用户确认的具体电表。多个电表时按该编号读取，不擅自采用第一台。旧版七字段配置仍兼容；可选字段还包括 `dormRoom`、`portalDormAddress`。旧的个人脚本使用不同的 Keychain 前缀时不会自动同步，需由本人决定是否导入兼容配置。

## 失败和取消

- 取消登录、宿舍选择或最后保存，不替换旧配置。
- 电表未匹配时可先保存校园卡，稍后运行「选择 / 更换宿舍」。
- 校园卡或电费失败时不把缺失余额显示为 0；保留同一账号、同一电表的上次结果并标记缓存。
- 换账号或电表后隔离缓存，不显示旧账号的余额。
- 新配置按整份提交；保存成功但预览失败时，提示重新打开「查看双余额」。
- 仍可用「更多工具」中的官方配置导入和手动配置作为备用，不必删除 App 或清空原有 Keychain。

## 为什么这次先不用 PWA

网页可以做下载入口，但它不能读取另一个域名（学校官方登录页）的存储。学校余额 API 的跨域预检有返回允许，但这不代表官网会把登录凭据回传给第三方网页。只为了获取参数再多安装一层网页，会增加步骤。

当前交付以一个 Scriptable 脚本完成官方登录、配置和显示，不依赖项目云服务、维护者电脑或家庭网络，也没有额外的 iPhone 签名步骤。PWA 下载入口以后可以在不传输个人登录信息的前提下补充；它不是本轮已经实现或已发布的功能。

## 开发与测试

`tools/onboarding-core.js` 包含有界宿舍匹配和配置校验；`tools/onboarding/official-login.js` 仅在允许的学校来源读取指定的门户字段和校园会话；`tools/onboarding/scriptable-flow.js` 提供 Scriptable 登录、确认与保存。运行 `python3 tools/sync_onboarding.py` 后将这些本地审查源嵌入单个小组件脚本，不运行远程下载的代码。

```bash
python3 tools/sync_onboarding.py
python3 -m unittest discover -s tests -v
node tests/test_scriptable.cjs
node tests/test_export.cjs
node tests/test_onboarding.cjs
```

Scriptable 官方 API 依据：[WebView](https://docs.scriptable.app/webview/)、[DocumentPicker](https://docs.scriptable.app/documentpicker/)。官方 API 能力说明不能替代本校真实账户与设备验收。
