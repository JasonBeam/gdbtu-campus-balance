# 配置提取教程

目标是拿到自己的会话参数和最终选中的宿舍 ID。先尝试方法一；如果官方页面无法在普通浏览器保持登录，再使用方法二。

第一次接触 Scriptable 或 Python？可以先看 [AI 辅助上手教程](ai-guide.md)，让 AI 解释步骤、检查环境和分析脱敏报错。真实参数仍由你自己提取和填写，不要把个人配置或抓包发给 AI。

## 方法一：官方页面选好宿舍，再导出

**适用前提**：你能在可运行书签脚本或开发者工具的浏览器中，登录 `https://ecykt.gdbtu.edu.cn` 的官方 H5 页面。请从学校公布的入口进入，不要把私人带 Token 的链接发给别人。

1. 按官方流程登录，打开电费页面，选择自己的校区、楼栋与宿舍，确认官方页面已显示正确余额。
2. 打开电费详情可用于再次核对房间，但不需要手抄楼层 ID。官方页面保存的是最终宿舍节点。
3. 桌面浏览器可新建一个书签，名称填“导出校园配置”，将 [bookmarklet.txt](bookmarklet.txt) 中整行 `javascript:...` 设为书签地址；停留在官方已登录页面点击此书签。不要在项目主页上执行。
4. 也可在官方页面的开发者工具 Console 中，阅读并执行 [export-official-session.js](../tools/export-official-session.js)。浏览器若禁止粘贴，请遵循浏览器自己的提示；不需要关闭任何浏览器安全功能。
5. 工具显示已选宿舍名称；核对无误后点击“保存配置文件”或“复制配置”。凭据默认不显示在界面。
6. Web：把下载文件放在项目根目录，文件名保持 `config.local.json`。小组件：运行脚本，选择“导入官方页面配置”，粘贴 JSON。
7. 配置后先核对自己的官方页面余额。导入后清空含凭据的剪贴板。

工具只读取以下两项，不读取浏览器其他站点或历史：

| 官方本机记录 | 已确认的字段 | 提取结果 |
| --- | --- | --- |
| `elecampus_state` | `logintoken`、`loginInfo.syscustid`、`schoolid`、`custInfo.custid`、`loginInfo.timestamp` | 登录与校园卡参数 |
| `elecampus_state_new_power` | `selInfo.info.value`、`selInfo.fieldValue` | 最终宿舍 ID 与供你核对的名称 |

以上结构来自 2026-10-16 读取的官方公开前端。工具不访问远端接口、不上传凭据、不会替你登录、不会改变宿舍绑定。

### 不能把它称为“所有人免抓包”

微信内登录状态通常不与 Safari 或 Chrome 共享；把公开首页换个浏览器打开不一定能沿用微信会话。微信内也可能不能运行书签脚本。出现缺少参数时，先在同一浏览器完成官方登录并重新选宿舍；若官方只允许微信入口，使用下面的备用方法。不要安装声称能“绕过微信登录”的插件。

`getBuildingInfo` 在官方前端中存在，并通过 `buildingID` 递归加载下一级；但它仍需要合法登录。当前版本不批量拉取宿舍目录，也不把该接口存在当作能匿名获取所有信息的证明。

## 方法二：只复制自己的余额请求

如果方法一不可用，可使用自己熟悉的本机调试工具，例如 iPhone Stream、电脑浏览器 Network 面板。在学校官方页面查询自己的余额；不要抓取其他 App 的流量。

若工具要求安装 HTTPS 调试证书，这是设备级操作，请先阅读该工具官方说明，自行决定；本项目不自动安装证书或修改代理。完成后按工具说明停止捕获并移除不再需要的调试配置。

### 电费

找到发往以下路径的 **POST** 请求：

```text
主机：ecykt.gdbtu.edu.cn
路径：/ykt-mini/api/electricnew/service
请求体 server：/api/getMeterStatus
```

从自己的请求体复制 `syscustid`、`acc_token`、`areacode`、`buildingID`。某些工具还会在请求头显示 `acc_token`，两者应来自同一有效会话。

示例仅表示字段结构，以下值不能用于登录：

```json
{
  "server": "/api/getMeterStatus",
  "syscustid": "你的用户标识",
  "acc_token": "你的当前登录凭据",
  "areacode": "以自己请求为准",
  "buildingID": "你选中的最终宿舍节点"
}
```

只显示余额不需要 `comAddress`、楼层 ID、房号文本。电表返回的 `leftMoney` 单位为元；它与 `remaining`（剩余电量）是不同字段。

### 校园卡

在官方页面打开校园卡余额，查找：

```text
/ykt-mini/scanpay/getUserBalance
```

从自己的请求体复制 `custid`。它与 `syscustid` 不能互换。本项目会在只有一个绑定账户时尝试从 `getSysBindCustInfo` 获取，多个账户时要求你明确填写，不擅自选择。

## 常见问题

- **能不能只输入楼栋楼层房号？** 现有接口需要系统 ID 和合法登录凭据，文字地址本身不能替代。方法一利用官方页面已经做完的选择，省掉手抄和猜测。
- **余额显示 0？** 只有接口明确返回有效数字 0 才显示 0；未返回显示 `—`。负数余额按原值显示。
- **登录过期？** 在官方页面重新登录并导出配置，或从自己的新请求更新 `acc_token`。项目不保存学校密码，不承诺自动续期。
- **配置正确但电费不显示？** 先确认官方页面能查到同一宿舍；多个电表不会自动取第一个。接口结构变化时应重新适配。
- **校园卡无更新时间？** 某些响应只返回金额。界面显示“学校更新时间：未提供”，本机查询成功时间单独记录。
- **能不能给其他学校用？** 当前域名与协议仅针对广东工商职业技术大学，未验证其他学校。
- **能否直接把配置粘贴到 GitHub Issue 求助？** 不要。只描述错误类型，隐藏所有身份、Token、宿舍信息。
