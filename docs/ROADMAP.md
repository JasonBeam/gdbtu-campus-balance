# 距离稳定可维护版本还差什么

当前阶段：v0.1.0 实验性预发布。Release 解决按版本下载与追溯，不能替代真实环境验收。

## 稳定版前的主要验收

- [ ] 用自己的真实学校会话验收双余额、凭据过期与重新导入。
- [ ] 验证微信/Safari 的实际导出路径，并记录失败时的替代步骤。
- [ ] 验证 iPhone Small / Medium、深浅色与系统后台刷新。
- [ ] 用全新环境验收下载、首次启动、更新与配置/历史保留。
- [ ] 根据真实学校接口变化建立脱敏回归样例。

## 已补齐的协作基础

- 版本化 Release、用途明确的附件与 SHA-256 校验。
- 源码自动测试与自动打包，附件只取已提交文件。
- CHANGELOG、问题模板、贡献和安全说明。

后续按真实反馈确定优先级，不承诺未验证平台兼容性，也不以截图或 CI 绿灯代替完整验收。
