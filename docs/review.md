# 发布前审查记录

审查日期：2026-10-16。范围：从 BeamJasonESP 校园客户端、原 Dashboard 与现用 Scriptable 脚本中独立整理校园卡、宿舍电费查询、显示与接入教程；沿用原视觉与图表记录结构。

## 源项目发现与处理

| 发现 | 本项目处理 |
| --- | --- |
| 原 Scriptable 固定推送到个人 Mac companion | 移除个人地址和推送，直接查询学校 |
| 电费或日/月用量失败可阻断整个脚本 | 缩小到两种余额，各自查询，各自失败回退 |
| 固件与脚本的校园卡登录顺序不同 | 保留脚本的尽力初始化流程；失败仍可用已配置 custid 查询 |
| 部分路径直接选择第一个账户/电表 | 多结果要求核对，避免静默显示另一宿舍/账户 |
| 某些显示将本机抓取日期当作来源日期 | providerAt 与 fetchedAt 分开；没有学校时间就明确缺失 |
| 原脚本可复制并展示完整个人配置 | 新脚本不展示凭据；导入存 Keychain；官方页导出仅在点击后执行 |
| buildingID 字段名容易被理解为楼栋编号 | 对照官方代码确认其也用于最终叶节点；教程说明不手抄楼层 |

## 安全边界

- 发布目录由独立源码组成，不复制原项目 Git 历史、NVS、固件、备份、个人配置或抓包。
- Python 仅使用固定学校 HTTPS 主机；不跟随带凭据重定向。Scriptable 同样禁止跟随重定向。
- Dashboard 仅绑定 loopback；Host 与跨站请求检查；精确资源白名单，不可通过 HTTP 读取配置或源码；不设置跨域放行。
- 返回界面的是规范化金额、状态、时间和固定错误文本，无上游原始响应和身份标识。
- 当前余额缓存只在服务内存中，校园记录存独立私有 SQLite；Scriptable 缓存放独立 Keychain 前缀。未增加第三方分析。
- 最终发布封面使用真实截图排版；Web 数值与走势明确标注演示。手机实机截图中的真实数值经本人明确同意公开。生成过的 AI 概念封面未采用。

## 验证记录

- Python 自动化：数值与空值校验、响应包装、登录失败回退、custid 自动解析、多电表拒绝、独立缓存与时间保留、HTTP 资源白名单与 Host / 跨站限制。
- Scriptable Node 模拟：完整脚本语法、真实函数的请求构造、会话 ID / custid 解析、两项独立失败、20 分钟缓存和过期回退。
- 官方页导出工具：模拟本地记录、最终宿舍值提取、非官方域名拒绝、缺失参数拒绝；不替代真实登录验证。
- 浏览器：检查桌面、手机宽度、主题切换、控制台；保留演示页面实际截图。
- iPhone：现用个人脚本预览成功并留图，经本人明确同意公开真实数值；独立脚本 Small 演示渲染通过，留存另一张实机截图。
- 纠正手机运行入口检测：Scriptable 自身也有 module，不能仅凭 module.exports 判断 Node；现以 Script API 存在性区分。
