# 校园余额 v0.1.0 · 实验性预发布

首个版本化下载，适合试用、审阅与继续开发。

## 本版内容

- Added a standalone Scriptable widget for campus-card and dormitory-electricity balances.
- Added a local Python dashboard, private balance history, configuration examples and session-export tools.

## 下载选择

| 文件 | 内容 |
| --- | --- |
| `gdbtu-campus-balance-v0.1.0-source.zip` | 完整源码、Web 面板、工具、教程和许可 |
| `gdbtu-campus-balance-v0.1.0-scriptable.zip` | 小组件、配置示例、教程和许可 |
| `campus-balance-v0.1.0.js` | 可导入 Scriptable 的单文件，内附版权和字体许可声明 |
| `SHA256SUMS.txt` | 以上附件的 SHA-256 校验值 |

下载后先解压并阅读 README。完整源码包适合开发，按功能拆分的包方便按需取用。

## 已验证与限制

Python 单元测试、Scriptable 与配置导出模拟检查通过；已有 Web 和 Small 演示实机截图。

真实学校账户的独立版完整查询、Token 续期、微信内导出、Medium 实机布局和系统后台刷新仍待验证。需要 Python 3.10+；Scriptable 需要 iPhone 和 Scriptable App。

## 升级与数据

本次不修改查询协议或后台业务逻辑。更新前自行保存配置；保留 config.local.json、private/ 以及 Scriptable Keychain，勿用空示例覆盖。

校验附件：macOS 用 `shasum -a 256 -c SHA256SUMS.txt`；Linux 用 `sha256sum -c SHA256SUMS.txt`。请将本次所有附件下载至同一目录再校验。
